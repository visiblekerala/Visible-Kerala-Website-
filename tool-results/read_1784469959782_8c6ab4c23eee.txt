     1→# Visible Kerala — Single-Page Marketing Website Development Specification
     2→
     3→> **Target AI / Developer Handoff Document**  
     4→> **Project:** Visible Kerala Single-Page Marketing Website  
     5→> **Tech Stack:** HTML5, CSS3 (2.5D Claymorphism), Vanilla JavaScript (No external frameworks)  
     6→> **Core Feature:** Dual-Trigger Bilingual Architecture (English & Malayalam)
     7→
     8→---
     9→
    10→## 1. Executive Summary & Project Mandate
    11→
    12→**Visible Kerala** is a dedicated service helping small local businesses across Kerala—such as local shops, salons, tuition centres, homestays, bakeries, clinics, tailors, and auto repair garages—get discovered on Google, WhatsApp, and social media. 
    13→
    14→### Key Objectives:
    15→- **Tone:** Friendly local expert (*naadan* professional), approachable, plain language, proof over promises. Avoid sterile, corporate agency jargon.
    16→- **Visual Style:** Confident **2.5D / Claymorphism**. Soft, double-layered shadows, gentle gradients, rounded corners, floating blob shapes, and tactile 3D elements. Avoid sharp-edged, flat, or cold aesthetics.
    17→- **Performance:** Lightweight, fast-loading on 3G/4G cellular networks across Kerala (mobile-first design, total page weight `< 800KB`).
    18→- **Bilingual Accessibility:** Seamless switching between English and Malayalam without reloading the page or requiring separate URL structures.

    22→## 2. Brand Identity & Visual System
    23→
    24→### 2.1 Logo Handling & Asset Isolation (Critical)
    25→The provided reference asset (`Gemini_Generated_Image_.png`) features a solid warm-cream background. 
    26→1. **Isolation:** Cleanly remove the background (chroma-key or flood-fill removal) to export the pin-and-storefront mark and "Visible Kerala" wordmark as a transparent PNG/SVG asset.
    27→2. **Placement Rules:** Never place the logo directly on top of busy gradients or patterns. Always provide a calm, uncluttered patch of Cream Base (`#FBF3E6`), White, or solid Primary Green behind it.
    28→3. **Sizing Hierarchy:**
    29→   - **Navigation Bar:** Compact mark + wordmark (~40px height).
    30→   - **Hero Centerpiece:** Large, animated 3D bobbing centerpiece (~280px–360px height).

    80→## 3. Dual-Trigger Language Architecture
    81→
    82→To serve both tech-savvy business owners and traditional local shopkeepers without creating UX friction, implement a **Dual-Trigger Language System**:
    83→
    84→1. **Global Toggle Switch (Click/Tap):** A pill-shaped toggle switch located in the sticky navigation (`EN | മലയാളം`). When clicked:
    85→   - Triggers a smooth `250ms` DOM opacity fade (`0.7` to `1.0`).
    86→   - Swaps text nodes dynamically from the state object.
    87→   - Updates font-family classes (`body.lang-ml-active`).
    88→   - Persists user preference to `localStorage.setItem('vk_lang', lang)`.
    89→2. **Contextual Tooltip Previews (Hover / Long-Press):** Key headings, service badges, and navigation items include a custom data-attribute: `data-hover-ml="[Malayalam Translation]"`.
    90→   - When browsing in English mode, hovering over (desktop) or long-pressing (mobile) an element with `data-hover-ml` triggers a soft claymorphic tooltip floating above the cursor showing the Malayalam translation instantly.
    91→   - Prevents layout shift while aiding comprehension.

   354→## 6. Frontend Code Implementation Architecture
   355→
   356→### 6.1 Interactive JavaScript Controller (`app.js`)
   357→This script handles the dual-trigger translation engine, 3D claymorphic tilt physics, SVG path animation, and contextual tooltips without external libraries.
   358→
   359→```javascript
   360→document.addEventListener('DOMContentLoaded', () => {
   361→  let currentLang = localStorage.getItem('vk_lang') || 'en';
   362→  
   363→  // --- 1. Language Switching Engine ---
   364→  const langToggleBtn = document.getElementById('lang-toggle');
   365→  
   366→  function applyLanguage(lang) {
   367→    document.body.style.opacity = '0.7';
   368→    document.body.style.transition = 'opacity 250ms ease';
   369→    
   370→    setTimeout(() => {
   371→      // Apply Malayalam script typography class
   372→      document.body.classList.toggle('lang-ml-active', lang === 'ml');
   373→      
   374→      // Update DOM nodes bound with data-i18n
   375→      document.querySelectorAll('[data-i18n]').forEach(el => {
   376→        const keys = el.getAttribute('data-i18n').split('.');
   377→        let text = siteContent[lang];
   378→        keys.forEach(k => text = text ? text[k] : '');
   379→        if (text) {
   380→          if (el.tagName === 'INPUT' || el.tagName === 'TEXTAREA') {
   381→            el.placeholder = text;
   382→          } else {
   383→            el.textContent = text;
   384→          }
   385→        }
   386→      });
   387→      
   388→      // Re-render dynamic components (Package Cards & Select Dropdowns)
   389→      if (typeof renderPackages === 'function') renderPackages(lang);
   390→      if (typeof renderDropdown === 'function') renderDropdown(lang);
   391→      
   392→      document.body.style.opacity = '1';
   393→      localStorage.setItem('vk_lang', lang);
   394→      currentLang = lang;
   395→      
   396→      if (lang === 'ml') {
   397→        langToggleBtn.classList.add('active-ml');
   398→      } else {
   399→        langToggleBtn.classList.remove('active-ml');
   400→      }
   401→    }, 250);
   402→  }
   403→
   404→  if (langToggleBtn) {
   405→    langToggleBtn.addEventListener('click', () => {
   406→      applyLanguage(currentLang === 'en' ? 'ml' : 'en');
   407→    });
   408→  }
   409→
   410→  // --- 2. Contextual Hover Tooltips (English Mode Preview) ---
   411→  const hoverTooltip = document.createElement('div');
   412→  hoverTooltip.className = 'clay-tooltip';
   413→  document.body.appendChild(hoverTooltip);
   414→
   415→  document.querySelectorAll('[data-hover-ml]').forEach(el => {
   416→    el.addEventListener('mouseenter', (e) => {
   417→      if (currentLang === 'en') {
   418→        hoverTooltip.textContent = e.target.getAttribute('data-hover-ml');
   419→        hoverTooltip.classList.add('show');
   420→        const rect = e.target.getBoundingClientRect();
   421→        hoverTooltip.style.top = `${rect.top + window.scrollY - 45}px`;
   422→        hoverTooltip.style.left = `${rect.left + (rect.width / 2)}px`;
   423→      }
   424→    });
   425→    el.addEventListener('mouseleave', () => hoverTooltip.classList.remove('show'));
   426→  });
   427→
   428→  // --- 3. 3D Card Tilt Physics (Claymorphic Interactive Experience) ---
   429→  document.querySelectorAll('.clay-card-3d').forEach(card => {
   430→    card.addEventListener('mousemove', (e) => {
   431→      const rect = card.getBoundingClientRect();
   432→      const x = e.clientX - rect.left;
   433→      const y = e.clientY - rect.top;
   434→      
   435→      const centerX = rect.width / 2;
   436→      const centerY = rect.height / 2;
   437→      
   438→      const rotateX = ((y - centerY) / centerY) * -8;
   439→      const rotateY = ((x - centerX) / centerX) * 8;
   440→      
   441→      card.style.transform = `perspective(1000px) rotateX(${rotateX}deg) rotateY(${rotateY}deg) translateY(-5px)`;
   442→      card.style.boxShadow = `var(--clay-card-hover)`;
   443→    });
   444→
   445→    card.addEventListener('mouseleave', () => {
   446→      card.style.transform = `perspective(1000px) rotateX(0deg) rotateY(0deg) translateY(0px)`;
   447→      card.style.boxShadow = `var(--clay-shadow-md)`;
   448→    });
   449→  });
   450→
   451→  // --- 4. SVG Line Scroll Drawing (How It Works) ---
   452→  const path = document.querySelector('#workflow-path');
   453→  if (path) {
   454→    const pathLength = path.getTotalLength();
   455→    path.style.strokeDasharray = `${pathLength} ${pathLength}`;
   456→    path.style.strokeDashoffset = pathLength;
   457→
   458→    window.addEventListener('scroll', () => {
   459→      const scrollPercentage = (document.documentElement.scrollTop + document.body.scrollTop) / 
   460→                               (document.documentElement.scrollHeight - document.documentElement.clientHeight);
   461→      const drawLength = pathLength * scrollPercentage * 1.6;
   462→      path.style.strokeDashoffset = Math.max(0, pathLength - drawLength);
   463→    });
   464→  }
   465→
   466→  // --- 5. Intersection Observer for Scroll Reveals ---
   467→  const observer = new IntersectionObserver((entries) => {
   468→    entries.forEach(entry => {
   469→      if (entry.isIntersecting) {
   470→        entry.target.classList.add('reveal-visible');
   471→      }
   472→    });
   473→  }, { threshold: 0.15 });
   474→
   475→  document.querySelectorAll('.reveal-on-scroll').forEach(section => observer.observe(section));
   476→
   477→  // Initialize Page Language
   478→  applyLanguage(currentLang);
   479→});
   480→```

   662→Before handing off to Netlify, Vercel, or GitHub Pages deployment, execute this verification matrix:
   663→
   664→- [ ] **Asset Background Chroma-Key:** Check isolated PNG logo mark over `#1B5E20` deep green background to guarantee zero white fringe or jagged edge artifacts.
   665→- [ ] **Malayalam Script Rendering Test:** Verify rendering of Malayalam conjunct characters (കൂട്ടക്ഷരങ്ങൾ, e.g., ണ്ട, ക്ക, ച്ച) on iOS Safari and Android Chrome using `Baloo Chettan 2` and `Manjari`. Ensure character kerning does not overlap or break.
   666→- [ ] **Mobile Performance Budget:** Confirm compressed image sizes and lean CSS/JS payloads keep total initial page transfer weight **below 800KB** for fast 3G/4G cellular loading in rural Kerala districts.
   667→- [ ] **Form API Endpoint Verification:** Ensure Web3Forms or EmailJS API keys are properly configured and route submission notifications directly to `visiblekerala@gmail.com` within 60 seconds.
   668→- [ ] **WhatsApp Deep Link Encoding:** Check that URL encoded strings (`%20`, `%27`) in WhatsApp CTA links parse cleanly into pre-filled chat messages on desktop WhatsApp Web and mobile WhatsApp applications.
   669→- [ ] **3D Tilt Performance:** Verify that card hover animations using CSS `perspective()` run at a smooth 60fps without causing horizontal layout scrollbar overflow on tablet viewports (~768px).
